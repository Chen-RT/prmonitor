任务设置

控制 PR 同步频率，以及是否在发现新待评审 PR 后自动创建并执行 review。

Windows 提示 自动检测失败时，可填写 npm 全局 bin 目录，例如 C:\Users\你的用户名\AppData\Roaming\npm。

存储设置

管理员功能。切换存储前可测试连接；保存时会自动建表、迁移当前数据并读回校验。

需要管理员权限 当前用户不能修改存储配置，但仍可以查看当前存储状态。
选择存储后端
建议 普通可读文件用 data/store.json；希望节省空间或归档时用 data/store.json.gz 并启用 gzip。
数据库地址配置方式
格式 SQLite 支持 sqlite:// 或 file://；MySQL 支持 mysql:// 或 mariadb://。数据库需已存在，平台会自动创建用户、PR、任务、日志等业务表并同步当前数据。
